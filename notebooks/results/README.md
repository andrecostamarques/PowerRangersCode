# Results Analysis Notebooks

This directory contains notebooks designed for the detailed analysis and visualization of model training results and testing performance.

## Notebooks

- **[Test Analysis.ipynb](./Test%20Analysis.ipynb)**
  - **TLDR**: This notebook performs the final evaluation of the model using the test dataset.
  - **Function**: Evaluates generalization capabilities, calculates confusion matrices, and displays macro performance metrics (Precision, Recall, F1).

- **[ValidationNotebookAnalysis.ipynb](./ValidationNotebookAnalysis.ipynb)**
  - **TLDR**: This notebook compiles validation visualizations for model performance, currently focusing on the Resnet model trained on the Galaxy dataset.
  - **Function**: Comprehensive dashboard for analyzing training dynamics, loss curves, metric evolution, and feature selection mask behavior over epochs.
